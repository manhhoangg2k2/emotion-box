# [hwaG] Jar of Thoughts – Style Guide

## 🌈 Tone & Vibe
[hwaG] là một ứng dụng journaling tâm trạng mang phong cách nhẹ nhàng, lãng mạn và chữ ánh. Trải nghiệm giao diện nhằm mang đến sự an yên, gần gũi như viết nhật ký trong một quyển sổ tay cá nhân.

## 🎨 Visual Style
- **Màu sắc**: Pastel nhẹ nhàng (hồng, tím, xanh mint), tạo cảm giác mềm mại, trị liệu.
- **Kiểu chữ**: Quicksand (mềm mại, dễ đọc) và Playfair Display (nhấn mạnh, romantic)
- **Icon & minh hoạ**: Line-art, phác thảo dạng tay, giữ tính gọn.
- **Hiệu ứng**: Slide/fade mềm, animation nhẹ, chỉ dùng khi thật cần thiết

## 📅 UX Principles
- Tập trung vào **trải nghiệm cá nhân**: giao diện như một "không gian riêng"
- Sử dụng nhiều **khoảng trắng** để tăng sự thở và đồng cảm
- Các thành phần giao diện cần được thiết kế dễ nhận biết, nhớp nhàng và thân thiện

## 🖊 Color System
```dart
primary         // #FFC2D1 – hồng pastel (main theme)
secondary       // #C4B7E5 – tím pastel (supportive)
itemFocus       // #FFF0F5 – nền cho hộp cảm xúc
red             // #EF476F – tiêu cực
blue            // #70A1D7 – trung lập/tích cực
yellow          // #FFE29A – vui tươi
purple          // #B5A1E5 – thư giãn
neutralStroke   // #E4DDE2 – viền/hộp
backgroundHeader// #FBDCE2 – header hoặc splash
textDark        // #1A1A1A – text chính
textHint        // #B8B8B8 – gợi ý
textDisable     // #AFAFAF – không hoạt động
```

## 🛍þ Font System
- **Title/Main brand**: `Playfair Display`
- **Body/Text/Hint**: `Quicksand`
- Độ rỗ: 14–32px, spacing thoáng

## 📏 Components Style
- **Splash**: hũ + tim, trung tâm, gradient pastel
- **Emotion box**: minh hoạ là hũ/thẻ cứu/tờ
- **Emotion item**: lá thư, thẻ, gợi nhớ Polaroid
- **Popup/thêm cảm xúc**: bo góc lớn, animation mềm

## 🙏 Tagline & Emotion
> **"Feel. Write. Let go."**  
> Ghi chép tâm tư, thả xuống nỗi tâm, tự do bên trong

## 🚀 Kết

[hwaG] hướng đến việc tạo ra một app journaling có chiều sau, tinh tế và khổi gợi cảm xúc thật sự. Thiết kế hướng người dùng tới sự an yên và bên trong mình.
